# 智卡运价评估系统 · MVP

一个运价利润评估原型。输入线路、车型、能源类型与客户运价，立即算出：

- 能源费 / 过路费 / 司机人工 / 其他变动 四类成本
- 套用淡旺季系数后的 **总成本**
- **利润 / 利润率**、**保本运价**、**建议报价**
- 接单结论（可接单 / 议价 / 不接）

覆盖：**油车 / 新能源 / 氢电混合**、**整车专线 / 零担 / 城配**、**4.2m ~ 17.5m 全车型**。

## 运行方式（两种）

### A. 纯前端（零依赖，双击即用，免 Key）—— 推荐
直接双击 `index.html` 用浏览器打开。所有基线数据存于浏览器 localStorage。
**里程默认零配置即可用**：输入城市用内置坐标表秒出（免网）；输入到街道/门牌则自动调用**免费地理编码＋驾车路由**（OpenStreetMap / OSRM，**免 Key、免后端**）。全程无需申请任何地图服务。

### B. 前端 + 后端（可选，需自备高德 Key，最精确）
仅在你需要"真实驾车里程"且愿意自备高德 Key 时启用。把 Key 收进后端，**Key 不下发到浏览器**；后端定时联网拉取并缓存。
1. `cp server/config.example.json server/config.json` 并填写 `amap.key` / `amap.securityKey`。
2. `node server/server.js`（默认 http://127.0.0.1:3000）。
3. 浏览器打开 `http://127.0.0.1:3000`，在「数据基准 → 高级可选：高德后端」填入该地址保存。
> 安全说明：后端仅监听 127.0.0.1（本机）；高德 Key 只存于 server/config.json，绝不下发浏览器。默认的离线 / 免费地理编码模式完全不联网任何第三方 Key。

## 里程估算（默认免 Key）

打开网页即可用，**无需申请任何 Key**：
- **城市级（离线）**：内置 `cities.js` 全国主要城市经纬度，「计算里程」用 Haversine 直线距离 × 道路系数（默认 1.3，可调整）≈ 驾车里程。免网、即时。
- **街道级（联网·免 Key）**：输入"广州市天河区科韵路"这类详细地址，自动调用 OpenStreetMap 免费地理编码得到精确坐标，再经 OSRM 公共实例算真实驾车距离（或坐标直线×系数兜底）。免费、无需 Key。
- 精度：城市级直线×系数城际误差约 ±15%，足够筛单；街道级接近真实路网。
- 评估页「里程估算精度」可切换：自动 / 仅离线 / 街道级。

> 高德后端是"最精确真实驾车里程"的**可选项，而非必需**。多数用户用默认即可。

## 联网数据（定时自动拉取）

系统通过**数据源**联网获取最新能源价 / 运价指数，写入基线并打时间戳。

### 配置数据源（后端模式）
在 `server/config.json` 的 `dataRefresh.sources` 中列出数据源，后端按 `intervalMinutes`（默认 360 分钟）**定时自动拉取**；也可在前端点「联网更新」立即触发一次。

**演示源（开箱即用，验证闭环，非真实数据）：**
```json
{ "type": "demo", "name": "演示数据源(占位,非真实)" }
```

**真实 HTTP 源**（返回 JSON，字段名可用 `map` 映射到系统字段）：
```json
{
  "type": "http",
  "name": "我的油价数据源",
  "url": "https://你的数据源/最新油价.json",
  "map": {
    "dieselPrice": "data.diesel",
    "electricityPrice": "data.elec",
    "seasonMonthly": "data.season",
    "provinceFactor": "data.province"
  }
}
```
数据源只需返回关心的字段（缺省字段沿用上次值）。合法字段：`dieselPrice`、`electricityPrice`、`seasonMonthly`（12 个数）、`provinceFactor`（省份:系数 对象）。

**可选鉴权**：`dataRefresh.adminToken` 非空时，手动刷新接口需带 `?token=xxx`（定时任务不受影响）。

> 联网更新页支持两种用法：**前端直连**（填数据源 URL + 字段映射，浏览器直接拉取，注意 CORS）或**后端代理**（填 backendUrl，由服务端转发，规避跨域）。内置三个免 Key 预设，一点即用。

### 接任意真实数据源（免 Key 预设或自填）
打开「联网更新」页：
1. **选预设或填数据源 URL**：可直接选内置预设（OpenVan.camp / xxapi / 澄曜），或粘贴任意返回 JSON 的真实地址。
2. **字段映射**：把响应里的字段用「JSON 路径」对应到系统字段。支持嵌套路径，例如 `data.CN.prices.diesel` 表示 `响应.data.CN.prices.diesel`，`data.0.n0` 表示 `响应.data[0].n0`。
3. 点「**测试数据源（预览原始返回）**」→ 黑框里显示原始 JSON，用来确认字段路径对不对。
4. 确认后点「立即拉取最新数据」即写入基线。

系统内置三个**免 Key 真实数据源预设**（「联网更新」页一点即用）：
- **OpenVan.camp 全球油价**（CORS 开放、浏览器直连免后端）：`https://openvan.camp/api/fuel/prices`，自动映射到 `data.CN.prices.diesel`（中国柴油价，元/L）。
- **xxapi 中国分省油价**（免 Key，一次返回全国）：`https://v2.xxapi.cn/api/oilPrice`，默认取首条省份 `data.0.n0`（0#柴油）；如需指定省份，把映射里的 `0` 换成对应序号，或填后端地址走代理规避跨域。
- **澄曜 中国分省油价**（免 Key）：`https://api.ruseo.cn/api/oilprice`，默认 `data.list.0.diesel_0`。

也可粘贴任意返回 JSON 的真实数据源，用「字段映射」对应到柴油价 / 充电价等（支持 `data.CN.prices.diesel` 这类嵌套路径）。沙箱环境因代理限制无法访问外网，请在**你自己的机器**上运行验证。

### 推荐真实数据源方向
- 柴油价：OpenVan.camp（全球·免Key·CORS）、xxapi / 澄曜（中国分省·免Key）、或付费大宗数据（卓创、隆众）
- 充电价：充电桩聚合（特来电 / 星星充电等开放价）
- 运价指数：中国公路物流运价指数（中物联周度发布）

## 模型公式

```
利润 = 客户运价 + 回程货收入 − 总成本
总成本 =（能源费 + 过路费 + 司机人工 + 其他变动）× 淡旺季系数
```

- 能源费：油车 = 柴油价 × 百公里油耗 × 往返里程 ÷ 100；新能源 = 充电价 × 百公里电耗 × 往返里程 ÷ 100；**氢电混合 = 加氢价 × 百公里氢耗 ＋ 充电价 × 百公里电耗**（燃料电池供氢 + 动力电池补电，双能源融合核算）
- 过路费：车型档位费率（元/km）× 省份系数 × 往返里程
- 司机人工：（日工资 + 食宿）× 往返天数（往返里程 ÷ 车型日均里程，向上取整）
- 其他变动：轮胎/维修 + 保险分摊（元/km）× 往返里程 + 装卸费（零担按吨、其余按趟）
- 淡旺季系数：旺季运力紧张成本上浮（>1），淡季下浮（<1）；可由联网运价指数校准

> 往返成本已计入（车辆需返回）。回程若有货，填「回程货收入」冲减空返成本，解决"账面盈利实际亏"。

## 数据基准（可在「数据基准」页编辑）

| 模块 | 说明 |
|------|------|
| 能源价 | 柴油 元/L、充电 元/kWh、加氢 元/kg |
| 车型库 | 各车型油耗/电耗、日工资、日均里程、食宿 |
| 过路费 | 按车型类别的 元/km 费率 + 省份系数 |
| 淡旺季 | 12 个月成本系数 |
| 阈值 | 可接单的最低利润率（默认 8%） |

默认值基于 **2026-09 公开渠道调研**（非占位猜测），数据来源见 `data.js` 的 `meta.notes` 与下方「基线数据来源」。例如：0# 柴油 8.0 元/L（2026-09-24 调价后全国均价）、充电 0.75 元/kWh（自有桩 0.5–0.6 / 公共快充 1.0–1.5）、公路物流运价指数约 1048、各车型油耗/电耗取公开实测中值。

> **重要**：公开参考值 ≠ 你的真实成本。评估准不准，取决于你自己的运营数据。请尽快用「真实数据/校准」页录入真实成交，让系统自动校准（见下节）。

## 真实成交录入与校准（解决"真实数据少"）

基线再准也只是"行业平均"。本系统用"录入真实成交 → 自动校准"的闭环，把少量数据变成越来越准的模型：

1. 打开「**真实数据/校准**」页，逐单录入：线路、车型、能源、模式、月份、里程、客户运价、回程收入，以及**实际总成本**或**实际利润**（二选一）。
2. 系统对每单用当前模型跑一遍（未校准），与你的实际值对比，列出**成本偏差 %**（绿/黄/红）。
3. 点「**用已录入数据重新校准**」，系统计算校准系数 = 平均(实际总成本 ÷ 模型估算总成本)，并把它应用到后续所有评估：
   - 校准系数会乘进总成本（例如 ×0.88 表示模型此前系统性高估 12%，已修正）。
   - 系数被夹在 [0.5, 2.0] 防止异常样本带偏。
   - 样本不足 3 单时界面会提示"仅供参考"，建议继续积累。
4. 「数据基准」页顶部可见当前校准系数；「评估」结果明细里也显示"校准系数"与"能源价 ±10% 稳健性提示"。

> 校准现支持**按「车型·能源·模式」分组**：录入多单后，系统会为不同分组分别计算系数（如 9.6m 油车整车专线 与 17.5m 新能源零担 各自一套），评估时自动套用对应分组的系数，比单一全局系数更准；未匹配到分组时回退全局系数。分组校准与手动改「数据基准」参数可并行使用。

## 回程货池与自动匹配（解决"空返亏"）

去程有货、回程空驶是最易造成"账面有利润、实际亏"的场景。本系统用"回程货池 + 自动匹配"把这部分潜在收入显性化：

1. 打开「**回程货**」页，把你能拿到的回程货源逐条加入货池：名称、起运城市、目的城市、所需车型、计费方式（一口价 / 元·km）、价格、货量。
   - 起运城市要 = 评估页的「终点」，目的城市要 = 评估页的「起点」——系统按"终点→起点"找能顺路带回的货。
2. 回到「**评估**」页，填好起点 / 终点 / 车型 / 里程后，点「**🔍 匹配回程货池**」：
   - 系统筛出**线路一致（终点→起点）且车型匹配**的回程货源，列出每条的估算回程收入（一口价直接取；元·km 则 × 往返里程）。
   - 点「**应用此回程收入**」即把该金额填入"回程货收入"，结果页利润、保本运价、建议报价随之更新。
3. 回程收入进入公式：利润 = 客户运价 + 回程收入 − 总成本，直接冲减空返成本。

> 货池随账号存于本地；也可视作"合作货主 / 专线回程资源"的简单台账。可带回程货越多，空返越能被填掉。

## 基线数据来源（2026-09 公开调研）

- **柴油价**：2026-09-24 国家发改委调价后全国 0# 柴油约 7.86–8.3 元/L，取均价 8.0（北京 8.02 / 广东 7.98 / 山东 8.21 / 河南 8.29）。
- **充电价**：自有/谷电桩约 0.5–0.6 元/kWh，公共快充约 1.0–1.5 元/kWh，取折中 0.75。
- **公路物流运价指数**：中物联 2026-09-18 周报 综合 1048.29 / 整车 1053.95 / 零担重货 1053.92 / 零担轻货 1024.21。
- **油车油耗 / 新能源电耗 / 氢电氢耗**：卡车油耗实测、新能源重卡评测公开数据（太平洋汽车 / 有驾 / 易车等）：4.2m≈12L·30kWh·2.0kg、6.8m≈18L·50kWh·3.5kg、9.6m≈32L·90kWh·6.0kg、13m≈40L·150kWh·8.0kg、17.5m≈48L·160kWh·10.0kg（氢耗为燃料电池重卡按载重估算的公示能耗）。
- **司机日薪、过路费、轮胎维修、保险分摊**：行业运营经验区间，需按你车队实际微调。
